# Support QuantumAtom

QuantumAtom is an independent educational C++/OpenGL project for exploring hydrogen-like atomic orbitals in real time.

If QuantumAtom helps you learn, teach, demonstrate, or build scientific visualization work, the most useful support is:

- Star and share the repository.
- Cite the project in educational material, demos, or research notes.
- Report bugs with your OS, GPU, compiler, and OpenGL version.
- Contribute screenshots, performance profiles, portability fixes, or educational examples.
- Sponsor development when a funding link is available.

Financial support helps fund study costs, development time, hardware, testing across systems, and future educational visualization work.

## Current Funding Plan

The intended funding setup is:

- GitHub Sponsors for recurring support from developers and educators.
- A simple tip page such as Ko-fi for one-time support.
- Open Collective later if the project grows into a larger community effort.

After the funding accounts are active, add the links through `.github/FUNDING.yml` so GitHub displays a Sponsor button on the repository.
